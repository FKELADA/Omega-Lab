## 1. Conventions

| Topic | Convention |
|---|---|
| Phasor notation | Underlined in equations: $\underline V$, $\underline I$, $\underline Z$. |
| Phasor magnitude | **Peak** in lessons 1.4 and 2.1, where waveforms are introduced. **RMS** from lesson 2.2 onwards, as in all power-system work: $v(t) = \sqrt2\,\lvert\underline V\rvert\cos(\omega t + \angle\underline V)$. Lesson 2.2 states the switch explicitly. |
| Time reference | Sources are $\cos\omega t$ (phase 0) unless stated, so $v(t) = \operatorname{Re}\{\underline V e^{j\omega t}\}$. Exception: lessons 1.3 and 2.7 use $\sin$, the natural choice for RMS and Fourier series. |
| Impedance angle | $\varphi = \arg \underline Z$. $\varphi > 0$: inductive, current **lags**. $\varphi < 0$: capacitive, current **leads**. |
| Complex power | $\underline S = \underline V\,\underline I^{*} = P + jQ$. $Q > 0$ is absorbed by an inductive load. |
| Three-phase | Sequence a, b, c with $\underline V_b = \underline V_a\angle{-120°}$ and $\underline V_c = \underline V_a\angle{+120°}$. Operator $a = e^{j120°}$. |
| Clarke | Amplitude-invariant: $v_\alpha = \tfrac23(v_a - \tfrac12 v_b - \tfrac12 v_c)$, $v_\beta = \tfrac1{\sqrt3}(v_b - v_c)$. So $p = \tfrac32(v_d i_d + v_q i_q)$. |
| Park | $v_d + j v_q = (v_\alpha + j v_\beta)\,e^{-j\theta_{dq}}$, with $d$ aligned with $\alpha$ at $\theta_{dq} = 0$. |
| Per-unit | One power base $S_b$ (three-phase); voltage bases follow the transformer ratios; $I_b = S_b/(\sqrt3 V_b)$, $Z_b = V_b^2/S_b$. |
| Numbers | Shown with 3 significant digits and SI prefixes, in the reader's language (decimal comma in French). Values below $10^{-11}$ are round-off and shown as 0. |

## 2. Numerical core

All of Modules 1–2 run in the browser. There is no server and no round-trip, so every slider
updates instantly. Code: `web/src/lib/core/` and `web/src/lib/models/`.

### 2.1 Exact simulation of linear circuits

A linear circuit is written as $\dot x = A x + B u$.

**Exact zero-order-hold step.** With the input held constant over a step $h$, the step is
integrated exactly with one matrix exponential of an augmented matrix:

$$
\exp\!\left(\begin{bmatrix} A & B \\ 0 & 0 \end{bmatrix} h\right) = \begin{bmatrix} \Phi & \Gamma \\ 0 & I \end{bmatrix},
\qquad x_{k+1} = \Phi\,x_k + \Gamma\,u_k .
$$

The plotted points are therefore exact samples of the true solution, whatever the step size.
Stiff circuits (tiny $L$ or $C$) cannot make the solver ring or go unstable.

**Matrix exponential.** Computed by scaling and squaring with a degree-6 Padé approximant:
- scale $A$ by $2^{-s}$ so that $\lVert A\rVert_1 \le 0.5$;
- solve $D\,E = N$ for the Padé numerator $N$ and denominator $D$;
- square the result $s$ times.

**Sinusoidal sources stay exact.** A source $\hat V\cos\omega t$ is generated by two extra
states $(c, s) = (\cos\omega t, \sin\omega t)$ with $\dot c = -\omega s$, $\dot s = \omega c$. The
circuit and its source then form one autonomous system $\dot x = A x$, and the matrix-exponential
step is still exact. There is no hold error on the sine. (Lesson 1.4.)

**Eigenvalues.**
- 2×2: closed form, robust at the double root of critical damping.
- Larger: characteristic polynomial by Faddeev–LeVerrier, then roots by Durand–Kerner.

**Energies** (lesson 1.2) are running trapezoidal integrals of $R i^2$ and $V i$ over the samples.

### 2.2 Sinusoidal steady state

Lessons 2.2–2.8 solve the circuit once with complex numbers. The waveforms are then sampled:
every signal is $\operatorname{Re}\{\sqrt2\,\underline X e^{j\omega t}\}$ (`phasorRun`). Derived
signals such as $p = v\,i$ are computed sample by sample.

### 2.3 Time window

The oscilloscope's time window is chosen automatically.

| Lesson | Window |
|---|---|
| 1.2 (step response) | $7/\sigma_{min}$, where $\sigma_{min}$ is the slowest decay rate (7 time constants let the $t\,e^{-\alpha t}$ tail of critical damping settle). Underdamped: clamped to between 2 and 25 periods. Lossless: 6 periods. 1600 samples. |
| 1.4 (AC transient) | Enough periods for the transient to decay ($6/\sigma_{min}$), clamped to 6–120 periods. 48 samples per period, between 1600 and 9000 samples in total. |
| Steady-state lessons | 2 periods. |

The learner can lock the window. Freezing, sweeping or predicting locks it automatically, so that
traces stay comparable.

### 2.4 Sketch analysis

- **Phase of a sketch** (lesson 2.2): least-squares fit of $a\cos\omega t - b\sin\omega t$ to the
  sketched points (`fitPhase`). This gives the sketch's amplitude $\sqrt{a^2+b^2}$ and phase
  $\operatorname{atan2}(b, a)$.
- **Score of a prediction:** the sketch is linearly interpolated at every simulation sample it
  covers.

$$
e_{rms} = \sqrt{\frac1n\sum_k\left(\frac{y_{sketch}(t_k) - y(t_k)}{\max\lvert y\rvert}\right)^2},
\qquad
\text{score} = 100\,\max(0,\,1 - e_{rms})\;\min\!\left(1,\ \frac{\text{coverage}}{0.6}\right)
$$

  Coverage is the fraction of the window the sketch spans. A sketch covering less than 60 % of
  the window is penalised.

## 3. The lesson format and shared features

A lesson is a typed data file, `lessons/<id>/experiment.ts`, exporting an `Experiment`
(`lib/lab/types.ts`). It declares:

| Field | Role |
|---|---|
| `model` | The physics: `simulate(params, tEnd)`, `poles(params)`, `window(params)`. |
| `info` | Derived quantities (poles, Q, power factor…) used by equations and step checks. |
| `params` | Sliders: range, default, log/linear scale, optional integer `step` or discrete `choices`. |
| `signals` | Traces available on the oscilloscope: unit, colour, default visibility, dashed or not. |
| `canvas`, `instruments` | The left-hand drawing and the panels under the oscilloscope. |
| `equations` | Live equation cards. Each has KaTeX built from current values, optional term-size `bars`, a `derive` sequence, a `note`, and the `personas` (profiles) that see it. |
| `steps` | Guided steps: Markdown text, an optional `hint`, and a `check(lab)` that marks the step done. |
| `predict` | Optional predict-then-reveal: which signal, a y-range that does not give the answer away, and a `diagnose` function that returns misconception feedback. |
| `bode`, `phasors` | Optional specifications for the frequency-response and phasor-diagram instruments. |

**Behaviour shared by every lesson:**

- **Hover cross-highlighting:** each equation term carries a term id (`R`, `L`, `C`, `S`, `i`,
  `a`, `b`, `c`, `n`…). Hovering a term, slider, trace or circuit element highlights it everywhere.
- **Concealment:** while a prediction is being sketched, every panel that would give the answer
  away is blurred.
- **Step completion is sticky:** once a check passes, the step stays done. Some checks require an
  earlier step (e.g. 2.4 step 5 requires step 4) so they cannot pass at page load.
- **Profiles:**
  - *Learner* sees the core cards.
  - *Engineer* adds utility-practice cards (standards, typical values, faults).
  - *Researcher* adds the mathematical-structure cards (state space, transfer functions,
    conventions).
- **URLs:** each lesson has one (`#1.4`), and the last step links to the next lesson.
- **Languages:** French and English throughout. The default follows the browser and is
  remembered per viewer.

## 5. Module 1 — Circuits, DC vs AC

### 1.2 RLC transients · `#1.2` · `lessons/rlc-step`

**Objectives.** After this lesson the learner can:
- explain why an inductor's current and a capacitor's voltage cannot jump;
- predict the shape of a series RLC step response from its damping ratio;
- relate the response to the poles in the s-plane and to energy moving between $L$ and $C$;
- recognise the switching-overvoltage mechanism behind capacitor-bank energisation.

**Model.** A series RLC circuit, initially de-energised, switched onto a DC source $V$ at $t=0$.
States $x = [i,\ v_C]$:

$$
L\frac{di}{dt} = V - R i - v_C, \qquad C\frac{dv_C}{dt} = i,
\qquad A = \begin{bmatrix} -R/L & -1/L \\ 1/C & 0 \end{bmatrix}.
$$

**Formulas shown.**
- KVL with live values and term bars: $V = Ri + L\,di/dt + v_C$.
- Characteristic equation $LCs^2 + RCs + 1 = 0$, with $\alpha = R/2L$, $\omega_0 = 1/\sqrt{LC}$,
  $\zeta = \alpha/\omega_0 = \tfrac R2\sqrt{C/L}$, $R_c = 2\sqrt{L/C}$. The derivation is shown on
  demand.
- Exact current, whose form changes with the regime:
  - underdamped: $\dfrac{V}{L\omega_d}e^{-\alpha t}\sin\omega_d t$
  - critical: $\dfrac VL\,t\,e^{-\alpha t}$
  - overdamped: $\dfrac{V}{L(s_1-s_2)}(e^{s_1t}-e^{s_2t})$
- Energy balance: $\int V i\,d\tau = \int R i^2 d\tau + \tfrac12 L i^2 + \tfrac12 C v_C^2$.
- *Engineer, Researcher:* switching overvoltage
  $v_{C,\max} = V\left(1 + e^{-\pi\zeta/\sqrt{1-\zeta^2}}\right)$ and $i_{\max} \lesssim V/Z_0$,
  with $Z_0 = \sqrt{L/C}$.
- *Researcher:* the state-space form, the numerical matrix $A$ and its eigenvalues.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| R | 0.1–200 Ω (log) | 2 Ω |
| L | 1 mH–1 H (log) | 10 mH |
| C | 1 µF–10 mF (log) | 100 µF |
| V | 1–50 V | 10 V |

The defaults give $\zeta = 0.1$, $\omega_0 = 1000$ rad/s and $R_c = 20\ \Omega$.

**Panels.**
- Schematic: click an element to probe it. The current dots are offset by the charge
  $q = C v_C$, so they stop when the capacitor is full and run back when the current reverses.
- s-plane: shaded stable half-plane, poles, the $\omega_0$ circle, the root locus in $R$ across
  its whole range, and frozen and swept poles.
- Energy balance: supplied energy against stored plus dissipated. The two bars are always the
  same length.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Predict $i(t)$ | Prediction revealed |
| 2 | Where does the voltage go? (scrub through time) | Cursor has reached 90 % of the window |
| 3 | Critical damping | $\lvert\zeta - 1\rvert < 0.01$ |
| 4 | Energy swinging between L and C | $\zeta < 0.05$ |
| 5 | Freeze and compare, then $L \times 4$ | A frozen run exists with $L/L_{frozen} \in [3.3, 4.8]$ |
| 6 | Poles are eigenvalues | $R$ is swept |

**Misconceptions detected** (y-range of the sketch: $\pm 1.15\,V/Z_0$, which bounds the current
in every regime):
- the current jumps at $t = 0^+$: sketch above 30 % of the peak in the first 4 % of the window;
- the current stays non-zero in DC steady state;
- no reversal although $\zeta < 1$;
- an oscillation although $\zeta \ge 1$.

**Tests.**
- Matrix exponential against a rotation matrix (12 digits), and at a large norm ($e^{-50}$).
- Eigenvalues: a 3×3 companion matrix, a complex pair, and agreement with the RLC pole formula.
- Simulated current against the closed form in all three regimes: relative error below $10^{-9}$.
- Energy conservation in all three regimes, to 3 decimal places.
- Steady state: $v_C \to V$ within 1 %, $i \to 0$.
- Regime classification.

### 1.3 AC sources and RMS · `#1.3` · `lessons/ac-rms`

**Objectives.** After this lesson the learner can:
- state that the power into a resistor is never negative and pulses at $2f$;
- define the RMS value as the DC equivalent for heating, and derive $\hat V/\sqrt2$;
- compute RMS, form factor and crest factor for common waveforms;
- explain why average-responding meters misread non-sinusoidal waveforms.

**Model.** A periodic source across a resistor (purely algebraic). Waveforms:
- sine $\hat V\sin\omega t$;
- square $\pm\hat V$;
- triangle $\tfrac{2\hat V}{\pi}\arcsin(\sin\omega t)$;
- DC $V$.

**Formulas.**

| Waveform | $V_{rms}$ | $\overline{\lvert v\rvert}$ | Form factor |
|---|---|---|---|
| Sine | $\hat V/\sqrt2$ | $2\hat V/\pi$ | 1.111 |
| Square | $\hat V$ | $\hat V$ | 1 |
| Triangle | $\hat V/\sqrt3$ | $\hat V/2$ | 1.155 |
| DC | $V$ | $V$ | 1 |

- $p = v^2/R$. For a sine, $p = \bar P(1 - \cos2\omega t)$.
- $\bar P = V_{rms}^2/R$.
- An average-responding meter displays $\dfrac{\pi}{2\sqrt2}\,\overline{\lvert v\rvert}$, which is
  exact only for a sine: +11.1 % on a square, −3.8 % on a triangle.
- *Researcher:* Parseval, $V_{rms}^2 = \sum V_{n,rms}^2$, checked on the square wave.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| Waveform | sine / square / triangle / DC | sine |
| $\hat V$ | 1–400 V | 325 V (230 V RMS mains) |
| f | 1–1000 Hz (log) | 50 Hz |
| R | 1–1000 Ω (log) | 52.9 Ω (≈ 1 kW on 230 V) |

**Panels.**
- Heater schematic: the resistor glows with $p(t)/p_{max}$, and a gauge shows $\bar P$.
- Two multimeters (true RMS and average-responding) with the meter error, crest factor, form
  factor and $\bar P$.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Predict $p(t)$ | Prediction revealed |
| 2 | Why √2? | Cursor has reached 90 % |
| 3 | Same heating with DC | DC selected and $V$ within 2 % of $325/\sqrt2$ |
| 4 | Fooling the multimeter | Square or triangle selected |

**Misconceptions detected** (y-range $[-0.65, 1.15]\,\hat V^2/R$, so "negative power" can be
drawn):
- power goes negative (sketch below −15 % of the peak);
- power pulses at $f$ instead of $2f$: the sketch has at most half as many rising crossings of
  the half-peak level as the true curve.

**Tests.**
- Numerical RMS (20 001 samples) equals the closed form for all four waveforms.
- The average-responding meter reads a square wave 1.1107 × too high.

### 1.4 Resonance · `#1.4` · `lessons/resonance`

**Objectives.** After this lesson the learner can:
- see that a transient dies away into the steady state that phasors predict;
- find the resonance $f_0$ and explain why the current is maximal and in phase there;
- explain how $\lvert V_C\rvert$ can reach $Q$ times the source voltage;
- relate bandwidth to $Q$, and recognise capacitive and inductive behaviour;
- connect series resonance to harmonic resonance of capacitor banks.

**Model.** A series RLC switched at $t=0$ onto $v_S = \hat V\cos\omega t$. The source is two
extra oscillator states (§2.1), so the simulation is exact. A dashed steady-state trace
$i_\infty = \operatorname{Re}\{\underline I e^{j\omega t}\}$ is shown for comparison.

**Formulas** (peak phasors).
- $\underline Z = R + j(\omega L - 1/\omega C)$, $\underline I = \underline V/\underline Z$.
- Phasor KVL $\underline V_S = \underline V_R + \underline V_L + \underline V_C$, with magnitude
  bars that can exceed 100 %.
- Resonance:
  - $f_0 = 1/(2\pi\sqrt{LC})$
  - $Q = \omega_0 L/R = \tfrac1R\sqrt{L/C}$
  - $\Delta f = f_0/Q = R/(2\pi L)$
  - $\lvert V_C(f_0)\rvert = Q\hat V$
  - half-power frequencies $f_{1,2} = \big(\sqrt{\alpha^2+\omega_0^2} \mp \alpha\big)/2\pi$
  - the derivation is shown on demand.
- *Engineer, Researcher:* harmonic order excited on a 50 Hz grid, $h_{res} = f_0/50$, and
  detuning reactors (tuned to about $h \approx 4.3$).
- *Researcher:* $Y(s) = \dfrac{Cs}{LCs^2 + RCs + 1}$, the same poles as lesson 1.2.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| f | 10–2000 Hz (log) | 100 Hz |
| R | 0.2–200 Ω (log) | 5 Ω |
| L | 1–100 mH (log) | 10 mH |
| C | 1 µF–1 mF (log) | 100 µF |
| $\hat V$ | 1–50 V | 10 V |

The defaults give $f_0 = 159$ Hz and $Q = 2$.

**Panels.**
- **Frequency response:** $\lvert I\rvert$ (A) and $\lvert V_C\rvert$ (V) on a log frequency axis,
  with a magnitude/phase toggle, an $f_0$ mark and the shaded half-power band. Clicking or dragging
  on it sets $f$.
- **Phasor diagram:** $\underline V_R \to \underline V_L \to \underline V_C$ head to tail, closing
  on $\underline V_S$. It rotates with the time cursor, and each arrow's shadow on the real axis is
  its instantaneous value.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Transient, then steady state | Cursor has reached 90 % |
| 2 | Find the resonance | $\lvert f/f_0 - 1\rvert < 1.5\ \%$ |
| 3 | Capacitor overvoltage | $\lvert V_C\rvert/\hat V \ge 5$ within 5 % of $f_0$ |
| 4 | Selectivity | $R$ is swept |
| 5 | The other side | $f > 1.5 f_0$ |

**Tests.**
- The simulated current settles on the phasor solution: last-period error below 0.2 % of
  $\lvert I\rvert$.
- The source is reproduced exactly at every sample: error below $10^{-9}$.
- At $f_0$: $\lvert I\rvert = V/R$ and $\lvert V_C\rvert/V = Q$.
- At $f_1$ and $f_2$: $\lvert I\rvert = I_{max}/\sqrt2$, and $f_2 - f_1 = \Delta f$.

## 6. Module 2 — The AC toolbox

### 2.1 Euler and the rotating vector · `#2.1` · `lessons/euler`

**Objectives.** After this lesson the learner can:
- read $\cos$ and $\sin$ as the shadows of $e^{j\theta}$;
- represent a sinusoid as a phasor, and add sinusoids of the same frequency as vectors;
- explain why $d/dt$ becomes $j\omega$, the origin of impedance;
- see why three balanced phases sum to zero.

**Model.** $v_k(t) = A_k\cos(\omega t + \varphi_k)$ for $k = 1, 2$, and their sum.

**Formulas.**
- $e^{j\theta} = \cos\theta + j\sin\theta$, with live $\theta$, $\cos$ and $\sin$ bars. The
  Taylor-series derivation is shown on demand.
- $v = \operatorname{Re}\{A e^{j\varphi} e^{j\omega t}\}$, $\underline V = A\angle\varphi$.
- $\underline V_1 + \underline V_2 = \lvert S\rvert\angle\varphi_S$, so
  $v_1 + v_2 = \lvert S\rvert\cos(\omega t + \varphi_S)$.
- *Researcher, Engineer:* $\tfrac{d}{dt}e^{j\omega t} = j\omega e^{j\omega t}$, hence
  $\underline V_L = j\omega L\,\underline I$.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| $A_1$, $A_2$ | 0–10 V | 5 V |
| $\varphi_1$ | −180 to 180° | 0° |
| $\varphi_2$ | −180 to 180° | 120° |
| f | 1–100 Hz | 50 Hz |

**Panels.**
- **Euler helix:** $e^{j(\omega t + \varphi_1)}$ in 3D, as an orthographic SVG projection. Drag to
  rotate, or pick a view:
  - 3D (azimuth 35°, elevation 22°);
  - side, giving the sine (0°, 0°);
  - top, giving the cosine (0°, 90°);
  - end-on, giving the circle (90°, 0°).
  The sum's helix can be overlaid.
- **Phasor diagram:** $\underline V_1$, $\underline V_2$ head to tail, and the resultant.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Predict $v_1 + v_2$ (5 V and 5 V, 120° apart) | Prediction revealed |
| 2 | Turn the helix | End-on view selected |
| 3 | Adding in phase | Phase gap < 3°, both amplitudes > 0.5 V |
| 4 | Cancelling out | $\lvert S\rvert < 5\ \%$ of $A_1$ |
| 5 | A glimpse of three-phase | $A_1 \approx A_2$ (5 %), $\varphi_1 = 120 \pm 3°$, $\varphi_2 = -120 \pm 3°$ |

**Misconception detected** (y-range $\pm1.1(A_1 + A_2)$): amplitudes simply add. The sketch peaks
above $1.35\lvert S\rvert$ and near $A_1 + A_2$; the feedback quotes the actual phase gap and
$\lvert S\rvert$.

**Tests.**
- The sampled sum equals the sinusoid of the summed phasors, error below $10^{-12}$.
- Unit phasors at 120° and 240° sum to $1\angle180°$.

### 2.2 Phasors and impedance · `#2.2` · `lessons/impedance`

**Objectives.** After this lesson the learner can:
- state the phase relation of R (in phase), L (current lags 90°) and C (current leads 90°), and
  explain it from the element laws;
- compute $\underline Z$ and $\underline I$ for single elements and RL/RC pairs;
- read the impedance triangle and the corner frequency $\lvert X\rvert = R$;
- work with RMS phasors.

**Model.** RMS source $V\angle0$ across one of R, L, C, R+L or R+C; steady state only.

**Formulas.**
- Element laws, from time domain to phasors:
  - $v_R = Ri \to \underline V = R\underline I$
  - $v_L = L\,di/dt \to \underline V = j\omega L\,\underline I$
  - $i_C = C\,dv/dt \to \underline V = \underline I/(j\omega C)$
- $\underline Z$ in rectangular and polar form, $\underline I = \underline V/\underline Z$, with a
  lead/lag note.
- $v(t) = \sqrt2\lvert V\rvert\cos\omega t$ and $i(t) = \sqrt2\lvert I\rvert\cos(\omega t - \varphi)$.
- *Researcher, Engineer:* $f_c = R/2\pi L$ or $1/2\pi RC$; typical $X/R$ ratios (about 10 for a
  power transformer, 0.3–1 for an LV cable).
- *Researcher:* $\underline Y = 1/\underline Z = G + jB$, the basis of $Y_{bus}$.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| Circuit | R / L / C / R+L / R+C | L |
| f | 5–5000 Hz (log) | 50 Hz |
| R | 1–1000 Ω (log) | 10 Ω |
| L | 1 mH–1 H (log) | 50 mH |
| C | 1 µF–2 mF (log) | 200 µF |
| V | 1–400 V RMS | 230 V |

**Panels.**
- Schematic that redraws for the selected circuit.
- Phasor diagram: $\underline I$ is drawn scaled by $\lvert Z\rvert$ so it is as long as
  $\underline V$; the angle is what matters, and the readout gives amperes.
- Impedance plane: the R, X, $\lvert Z\rvert$ triangle, the angle arc, and the locus of $Z$ over
  the frequency range.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Current in an inductor | Prediction revealed |
| 2 | And the capacitor? | C selected |
| 3 | Frequency matters | L selected and $f \ge 495$ Hz |
| 4 | At 45° | R+L selected and $\lvert\varphi - 45°\rvert < 2°$ |
| 5 | The locus of Z | R+C selected and $\lvert\varphi\rvert < 6°$ |

**Misconceptions detected.** The sketch's phase is found by least squares (§2.4) and compared
with the true lag. An error under 30° is accepted. Otherwise the feedback is one of:
- "in phase": an explanation from $v_L = L\,di/dt$;
- "leading": that is what a capacitor does;
- a generic message giving the sketched and true lags.

### 2.3 AC power: P, Q, S and power-factor correction · `#2.3` · `lessons/power`

**Objectives.** After this lesson the learner can:
- explain why $p(t)$ goes negative for a reactive load;
- split $p(t)$ into an active part (average $P$) and a reactive part (average zero, amplitude $Q$);
- use $\underline S = \underline V\underline I^*$, the power triangle and $\cos\varphi$;
- size a correction capacitor, and explain why overcompensating is harmful;
- relate the power factor to line current and losses.

**Model.** A 230 V supply feeding a motor (P, $\cos\varphi_M$ lagging) through a cable of
$R_\ell = 0.25\ \Omega$, with a shunt capacitor bank $C$ at the motor.
- $Q_M = P\tan\varphi_M$
- $\underline I_M = (\underline S_M/\underline V)^*$
- $\underline I_C = j\omega C\,\underline V$
- $\underline I = \underline I_M + \underline I_C$

**Formulas.**
- $\underline S = \underline V\underline I^* = P + jQ$, $\lvert S\rvert = VI$, $\cos\varphi = P/\lvert S\rvert$.
- $p(t) = P(1 + \cos2\omega t) + Q\sin2\omega t$, with bars for the two parts and the derivation
  on demand.
- $Q_C = \omega CV^2$, and the correction to 0.95:
  $C_{0.95} = \dfrac{P(\tan\varphi_M - \tan\varphi_{0.95})}{\omega V^2}$ (416 µF at the defaults).
- *Engineer, Researcher:* $P_{loss} = R_\ell\left(\dfrac{P}{V\cos\varphi}\right)^2 \propto 1/\cos^2\varphi$,
  $\tan\varphi = Q/P$, and the reactive-energy billing threshold.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| P | 1–50 kW (log) | 10 kW |
| $\cos\varphi_M$ | 0.3–1 | 0.7 |
| C | 0–1.5 mF | 0 |
| V | 100–400 V | 230 V |
| f | 50 / 60 Hz | 50 Hz |

**Panels.**
- Schematic: feeder losses, current readouts, and a $\cos\varphi$ dial (lead/lag).
- Power triangle: $P$, $Q_M$ up, $-Q_C$ back down, the source's $S$, the line current, and the
  losses relative to unity power factor.
- Phasor diagram: $\underline V$, $\underline I_M \to \underline I_C$ head to tail, and
  $\underline I$. All currents share one scale ($\lvert I_M\rvert$ drawn at 80 % of $\lvert V\rvert$).

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Predict a motor's power | Prediction revealed |
| 2 | Two parts | $p_Q$ shown and cursor has reached 90 % |
| 3 | Raise the power factor | $\cos\varphi \ge 0.95$, lagging |
| 4 | Fewer losses | $\cos\varphi > 0.99$ |
| 5 | Overcompensating | Leading, and $\cos\varphi < 0.95$ |

**Misconception detected** (y-range $[-1.1\lvert S\rvert,\ 1.15(P + \lvert S\rvert)]$): power
never goes negative. This is the natural carry-over from the heater of 1.3. It triggers when the
true $p$ dips below −10 % of $\lvert S\rvert$ and the sketch stays above −5 %.

**Tests.**
- $p = p_P + p_Q$ to $10^{-9}$, and the mean of $p$ equals $P$.
- $C_{0.95}$ gives exactly 0.95.
- Correction leaves $P$ unchanged and scales losses by $(0.7/0.95)^2$.

### 2.4 Three-phase systems · `#2.4` · `lessons/three-phase`

**Objectives.** After this lesson the learner can:
- show that balanced three-phase power is constant, and why that matters for machines;
- explain the neutral current under unbalance;
- predict the overvoltage caused by a broken neutral (Millman);
- relate phase and line voltages (230/400 V).

**Model.** A balanced 230 V source feeding a star of resistors $R_a$, $R_b$, $R_c$, with the
neutral connected or broken. In single-phase mode only phase a is connected.
- Broken neutral, by Millman's theorem: $\underline V_{N'} = \dfrac{\sum_k \underline V_k/R_k}{\sum_k 1/R_k}$
- Load voltages: $\underline U_k = \underline V_k - \underline V_{N'}$
- Neutral current: $\underline I_N = \sum_k \underline I_k$ (zero when the neutral is broken)

**Formulas.**
- The three phase voltages and $v_a + v_b + v_c = 0$, with live bars.
- $\underline I_N = \underline I_a + \underline I_b + \underline I_c$.
- $p = \sum v_k i_k = 3VI\cos\varphi$, constant. The derivation uses
  $\sum\cos^2(\theta - k\,120°) = 3/2$.
- $V_{ab} = \sqrt3\,V\angle30°$.
- *Engineer, Researcher:* Millman, with the drifted star point and the load voltages.
- *Researcher:* $a = e^{j120°}$, $1 + a + a^2 = 0$, as a preview of 2.8.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| Phases | 1 / 3 | 3 |
| Neutral | connected / broken | connected |
| $R_a$, $R_b$, $R_c$ | 5–500 Ω (log) | 26.45 Ω (2 kW each) |
| V | 100–400 V | 230 V |
| f | 50 / 60 Hz | 50 Hz |

**Panels.**
- Star schematic with a **clickable neutral switch**. Load voltages outside ±10 % turn orange.
- Phasor diagram: source phasors; with a drifted star point, also $\underline V_{N'}$ and the load
  voltages drawn from it.
- Phase balance: load voltages against the ±10 % band; line and neutral currents.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Predict the total power | Prediction revealed |
| 2 | Just one phase | Single-phase selected |
| 3 | Unbalance | Three-phase, neutral connected, $\lvert I_N\rvert > 3$ A |
| 4 | Broken neutral | Neutral broken and one load above $1.1\,V$ |
| 5 | 230 or 400 V? | Step 4 done, neutral reconnected, $\lvert I_N\rvert < 0.5$ A |

**Misconception detected** (y-range $[-0.3P, 2.3P]$): total power pulses like a single phase.
The sketch's spread exceeds $0.4P$.

**Tests.**
- Balanced: $I_N = 0$, $p$ constant to $10^{-9}$, $P = 3V^2/R$.
- Single phase: $p$ between 0 and $2P$.
- Broken neutral with $R_a = 10\ \Omega$ and $R_b = R_c = 200\ \Omega$: the currents sum to zero
  and $\lvert U_b\rvert > 300$ V.

### 2.5 Clarke and Park · `#2.5` · `lessons/park`

**Objectives.** After this lesson the learner can:
- see three phase quantities as the shadows of one space vector;
- apply the Clarke and Park transforms and explain why a balanced set becomes DC in the
  synchronous frame;
- describe how a PLL aligns the d axis (driving $v_q \to 0$);
- diagnose unbalance (2f ripple) and the 5th harmonic (6f ripple) from dq quantities;
- know the $\tfrac32$ power factor of the amplitude-invariant convention.

**Model.**
- $\theta = \omega t + \varphi$.
- $v_a = \sqrt2V\cos\theta$, $v_b = \sqrt2V\cos(\theta - 120°)$,
  $v_c = k_c\sqrt2V\cos(\theta + 120°)$.
- Each phase also carries $h_5\sqrt2V\cos 5(\theta - k\,120°)$.
- Clarke (amplitude-invariant), then Park with $\theta_{dq} = r\,\omega t$, where $r$ is the
  "frame speed" slider.

**Formulas.**
- The Clarke matrix and the live space vector $\underline v = v_\alpha + jv_\beta$.
- $v_d + jv_q = \underline v\,e^{-j\theta_{dq}}$, with bars. The note switches between
  "synchronous: DC" and "slip frequency $\omega - \omega_{dq}$".
- Ripple diagnosis: $\hat V_1 \to$ DC, $\hat V_2 \to 2\omega$, $h_5 \to 6\omega$.
- *Researcher, Engineer:* $p = \tfrac32(v_di_d + v_qi_q)$ and $q = \tfrac32(v_qi_d - v_di_q)$, with
  a warning about conventions.
- *Researcher:* $\dfrac{d\underline\psi_{dq}}{dt} = \underline v_{dq} - R\underline i_{dq} - j\omega_{dq}\underline\psi_{dq}$,
  the form used by G2ELin's machine and inverter models.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| Frame speed $\omega_{dq}/\omega$ | 0–1.5 | 1 |
| φ | −180 to 180° | 30° |
| $k_c$ | 0–1.5 | 1 |
| $h_5$ | 0–30 % | 0 |
| V | 100–400 V | 230 V |
| f | 1–60 Hz | 50 Hz |

**Panels.**
- **Fixed αβ plane:**
  - the a, b, c axes, the space vector and its trajectory, and the rotating d and q axes;
  - the vector's shadows on the a, b, c axes are the phase voltages.
- **Camera riding the dq frame:** the same picture rotated by $-\theta_{dq}$. A balanced set at
  $r = 1$ stands still.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Predict $v_d$ | Prediction revealed |
| 2 | Fixed frame | $r < 0.01$ |
| 3 | Aligning the d axis | $r \approx 1$ and $\lvert\varphi\rvert < 2°$ |
| 4 | An unbalance | $k_c \le 0.61$ |
| 5 | A harmonic | $h_5 \ge 10\ \%$ and $k_c \approx 1$ |

**Misconception detected** (y-range $\pm1.4\sqrt2V$): $v_d$ oscillates. The sketch's spread
exceeds $0.5\sqrt2V$.

**Tests.**
- Balanced and synchronous: $v_d = \sqrt2V$ and $v_q = 0$ at every sample (9 digits).
- $\arctan(v_q/v_d)$ equals φ.
- With $k_c = 0.5$: $V_2/V_1 > 0.15$, and the $v_d$ ripple amplitude equals $\hat V_2$.

**Limitation.** With $k_c \ne 1$ the set also has a zero-sequence component. Clarke removes it,
so the shadows drawn on the a, b, c axes then differ slightly from the actual phase voltages.

### 2.6 Per-unit system · `#2.6` · `lessons/per-unit`

**Objectives.** After this lesson the learner can:
- choose bases and derive $I_b$ and $Z_b$ in each voltage zone;
- convert nameplate impedances with the change-of-base formula;
- see that results do not depend on the chosen base, and that ideal transformers disappear;
- read a voltage profile, and use a tap changer and the power factor to correct it.

**Model.** One phase of a balanced system:

| Element | Data |
|---|---|
| Generator | 11 kV, held at 1 pu |
| T1 | 50 MVA, 11/132 kV, $x = 10\ \%$ |
| Line | $5 + j20\ \Omega$ at 132 kV |
| T2 | 40 MVA, 132/33 kV, $x = 8\ \%$, tap $t$ |
| Load | Constant impedance, sized for $P$ and $\cos\varphi$ at nominal 33 kV |

- The tap is modelled ideally: the load impedance is referred to the T2 primary as $z/t^2$, and
  the load voltage is $t$ times the primary-side voltage.
- Magnetising branches and transformer resistance are neglected.

**Formulas.**
- $S_b$, $V_b$, $I_b = S_b/(\sqrt3V_b)$, $Z_b = V_b^2/S_b$, $x_{pu} = x/x_b$.
- $z_{new} = z_{old}\,\dfrac{S_{new}}{S_{old}}\left(\dfrac{V_{old}}{V_{new}}\right)^2$. Example:
  T1 at 10 % on 50 MVA is 20 % on 100 MVA.
- $\underline I = 1/(z_{T1} + z_L + z_{T2} + z_{ch})$, and the load voltage in pu and kV.
- *Engineer, Researcher:* typical values. Transformer 0.05–0.15 pu; generator $x''_d$ 0.12–0.25 pu
  and $x_d$ 1–2 pu; voltage 0.95–1.05 pu.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| $S_{base}$ | 10 / 50 / 100 MVA | 100 MVA |
| P | 1–40 MW | 10 MW |
| $\cos\varphi$ | 0.7–1 | 0.9 |
| Tap $t$ | 0.9–1.1 pu | 1 |

Reference results: the load sits at 0.972 pu by default; 0.914 pu at 30 MW; 0.986 pu at 30 MW
with $t = 1.1$.

**Panels.**
- One-line diagram across the three zones, with each element in Ω and pu and each bus in pu and kV.
- Table of bases per zone.
- Voltage profile with the ±5 % band.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Changing the base | $S_{base} \ne 100$ MVA |
| 2 | Heavy load | $\lvert V_{load}\rvert < 0.95$ pu |
| 3 | The tap changer | Step 2 done, $\lvert V_{load}\rvert \ge 0.97$ pu with $t > 1$ |
| 4 | Power factor matters | $t \approx 1$ and $\cos\varphi > 0.995$ |

There is no prediction in this lesson: the learning is in the calculation, not in a waveform shape.

**Tests.**
- The load voltage is identical on 10 MVA and 100 MVA bases (12 digits).
- The zone bases are 11, 132 and 33 kV, and T1 is 0.2 pu on 100 MVA.
- Raising the tap raises the load voltage.

### 2.7 Harmonics and Fourier · `#2.7` · `lessons/fourier`

**Objectives.** After this lesson the learner can:
- build a periodic wave from sinusoids, and read a spectrum;
- compute THD, and link it to RMS through Parseval;
- recognise the Gibbs phenomenon and why smooth waves converge faster;
- identify the characteristic $6k \pm 1$ harmonics of a 6-pulse rectifier;
- hear that timbre is harmonic content.

**Model.** The partial sum $v_N = \hat V\sum_{n=1}^{N} b_n\sin n\theta$ against the exact target
waveform.

| Target | $b_n$ (unit amplitude) | THD |
|---|---|---|
| Square | $\dfrac{4}{n\pi}$, n odd | 48.3 % |
| Triangle | $\dfrac{8}{\pi^2n^2}(-1)^{(n-1)/2}$, n odd | 12.1 % |
| Sawtooth | $\dfrac{2}{n\pi}(-1)^{n+1}$ | 80.3 % |
| 6-pulse rectifier current (120° blocks) | $\dfrac{4}{n\pi}\cos\dfrac{n\pi}{6}$, n odd (zero for multiples of 3) | 31.1 % |

THD is computed from the exact RMS of the target:
$\mathrm{THD} = \sqrt{V_{rms}^2 - V_{1,rms}^2}\,/\,V_{1,rms}$. A truncated sum would underestimate
it.

**Formulas.**
- The series for the selected target, and the live partial sum against the target. The
  derivation for the square wave is shown on demand.
- $\mathrm{THD} = \sqrt{\sum_{n\ge2}V_n^2}/V_1$, and Parseval.
- *Researcher:* Gibbs. The overshoot tends to 8.95 % of the jump, which is 1.179 for a ±1 square.
- *Engineer, Researcher:* $h = kp \pm 1$, $I_h \approx I_1/h$; EN 50160 (voltage THD ≤ 8 %);
  IEEE 519.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| Target | square / triangle / sawtooth / 6-pulse rectifier | square |
| N | 1–49 (integers) | 1 |
| $\hat V$ | 1–400 V | 100 V |
| f | 1–60 Hz | 50 Hz |

**Panels.**
- **Fourier epicycles:** one rotating vector per harmonic, chained head to tail. The tip traces
  the partial sum over the last period.
- **Spectrum:** $\lvert b_n/b_1\rvert$ for $n \le 49$; harmonics beyond N are faded. It shows the
  THD of the target and of the partial sum.
- **Listen button:** plays the partial sum with WebAudio (a periodic wave from the $b_n$) at
  220 Hz for 1.3 s, so it is audible.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Building a square | Square and $N \ge 15$ |
| 2 | Gibbs | Square and $N \ge 45$ |
| 3 | The triangle converges fast | Triangle and $N \le 5$ |
| 4 | A rectifier's current | Rectifier selected |
| 5 | Hearing distortion | Listen clicked |

There is no prediction in this lesson: building the wave is itself the experiment.

**Tests.**
- With N = 49, every target is matched to within 0.06 at sample angles away from the jumps.
- THD values: square 48.3 %, triangle 12.1 %, rectifier 31.1 %.
- The rectifier has non-zero $b_n$ only for odd $n$ that are not multiples of 3.

### 2.8 Symmetrical components · `#2.8` · `lessons/sequences`

**Objectives.** After this lesson the learner can:
- decompose any three phasors into positive, negative and zero sequences (Fortescue);
- relate each sequence to its physical effect (torque, rotor heating, neutral/earth current);
- recognise the signatures of a phase swap, a pure zero sequence and a phase-to-ground fault;
- compute the unbalance factor, and compare it with EN 50160.

**Model.** Phasors $\underline V_a = M_a\angle0$, $\underline V_b = M_b\angle A_b$,
$\underline V_c = M_c\angle A_c$ (pu):

$$
\begin{bmatrix}\underline V_0\\ \underline V_1\\ \underline V_2\end{bmatrix} = \frac13\begin{bmatrix}1&1&1\\1&a&a^2\\1&a^2&a\end{bmatrix}\begin{bmatrix}\underline V_a\\ \underline V_b\\ \underline V_c\end{bmatrix},
\qquad \mathrm{VUF} = \frac{\lvert\underline V_2\rvert}{\lvert\underline V_1\rvert}.
$$

**Formulas.**
- The operator $a$.
- Fortescue, with live values and $\lvert V_1\rvert$, $\lvert V_2\rvert$, $\lvert V_0\rvert$ bars.
- What each sequence does.
- *Engineer, Researcher:* the VUF against the EN 50160 limit (2 %).
- *Researcher, Engineer:* sequence networks; a phase-to-ground fault gives
  $\underline I_1 = \underline I_2 = \underline I_0 = \underline V_f/(\underline Z_1 + \underline Z_2 + \underline Z_0)$.

**Parameters.**

| Parameter | Range | Default |
|---|---|---|
| $M_a$, $M_b$ | 0–1.5 pu | 1 |
| $M_c$ | 0–1.5 pu | 0.6 (a dip on phase c) |
| $A_b$ | −180 to 180° | −120° |
| $A_c$ | −180 to 180° | 120° |
| f | 1–60 Hz | 50 Hz |

**Panels.**
- Phasor diagram of $\underline V_a$, $\underline V_b$, $\underline V_c$, on the canvas side.
- Three sequence wheels (positive, negative, zero) that rotate with the time cursor, the VUF, and
  presets: balanced, b ↔ c, phase a to ground, dip on c, pure zero.

**Guided steps.**

| # | Step | Done when |
|---|---|---|
| 1 | Rebalancing | VUF < 0.5 % and $\lvert V_1\rvert > 0.9$ |
| 2 | Swapping two phases | $\lvert V_2\rvert > 0.9$ and $\lvert V_1\rvert < 0.05$ |
| 3 | Pure zero sequence | $\lvert V_0\rvert > 0.9$ and $\lvert V_1\rvert < 0.05$ |
| 4 | A phase-to-ground fault | $M_a < 0.02$, $\lvert V_1\rvert = 2/3 \pm 0.02$, $\lvert V_2\rvert = 1/3 \pm 0.02$ |
| 5 | At the limit of the standard | 1 % ≤ VUF ≤ 2 % |

A dip of $\Delta V$ on one phase gives roughly $\lvert V_2\rvert \approx \Delta V/3$, which is the
hint for step 5.

**Tests.**
- Balanced: positive sequence only.
- b and c swapped: negative sequence only.
- $\underline V_0 + \underline V_1 + \underline V_2 = \underline V_a$.
